## About this codebase

This is the codebase responsible for hosting the Philotimo Supper Club, a creation by Nikki Reklitis and built by Charis Web Design. 

The site dispalys content about the premis of the supper club, shows past and upcoming events, and allows users to register for upcoming events.

This site is built with Next.js with React for the front-end, Sanity.io as a headless CMS for data management, and Tailwind for styling.

## For development

You will need a new .env.local file at the root of the project on each new device or account to run the project locally. This file needs a sanity-project-id, sanity-project-version, sanity-project-dataset, and a sanity-read token set to viewer.
